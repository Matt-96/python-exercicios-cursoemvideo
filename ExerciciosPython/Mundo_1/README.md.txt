# 🐍 Mundo 1: Fundamentos de Python

Este diretório contém os primeiros 35 desafios do curso, focados em construir a base necessária para qualquer programador.

## 📑 Conteúdos Abordados:
- **Primeiros Passos:** Configuração de ambiente e comandos básicos.
- **Tratamento de Dados:** Tipos primitivos (`int`, `float`, `str`, `bool`) e manipulação de strings.
- **Operações Aritméticas:** Cálculos, ordem de precedência e módulos.
- **Estruturas de Controle:** Condições simples e compostas (`if/else`).

## 🏆 Desafio de Destaque:
Acredito que os exercícios de **Manipulação de Strings (ex022 a ex027)** foram essenciais para entender como o Python lida com dados de texto de forma eficiente.
