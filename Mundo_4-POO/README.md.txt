# 🏛️ Mundo 4: Programação Orientada a Objetos (OOP)

Este repositório é apenas uma documentação da minha jornada de aprendizado em **POO**, um dos pilares fundamentais para o desenvolvimento de software profissional e requisito essencial para minha próxima etapa acadêmica.

## 🎯 Objetivos de Aprendizado
* **Classes e Objetos**: Mapeamento de entidades do mundo real para o código.
* **Atributos e Métodos**: Definição de estados e comportamentos.
* **Encapsulamento**: Proteção de dados e integridade dos objetos.
* **Abstração**: Foco no que o objeto faz, escondendo a complexidade de como ele faz.
